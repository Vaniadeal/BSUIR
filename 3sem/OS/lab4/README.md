# Модель файловой системы: Вариант 2 (Одноуровневая ФС, связанный список блоков)

Данный проект представляет собой полнофункциональную программную модель файловой системы на языке C++ (C++17) в соответствии с заданием Лабораторной работы №4 («Изучение организации файловой системы»).

## Спецификация варианта 2
- **Логическая организация каталогов**: Одноуровневая файловая система (Single-Level / Flat Directory). Все файлы располагаются в едином корневом каталоге; уникальность имен обеспечивается в пределах всего диска. Операция перемещения (`mv` / `move`) эквивалентна безопасному переименованию без физического перемещения блоков.
- **Физическая организация файлов**: Связанный список блоков (Linked list of blocks). Каждый физический блок данных содержит структуру-заголовок `BlockHeader` с указателем `next_block` на следующий блок файла (или `-1` для признака конца файла EOF) и счетчиком полезных байт `data_size`.
- **Управление свободным пространством**: Битовая карта свободных блоков (Free Block Bitmap).

## Сборка и запуск

### Требования
- Компилятор C++ с поддержкой стандарта C++17 (g++ или clang++)
- CMake (>= 3.16) и Make
- Python 3 (с установленными `matplotlib` и `pandas` для генерации графиков)

### Быстрые команды через Makefile:
```bash
# 1. Сборка проекта
make

# 2. Запуск модульных тестов
make test

# 3. Запуск нагрузочного тестирования и генерации графиков
make bench

# 4. Запуск интерактивной оболочки (на виртуальном диске-образе virtual_disk.bin)
make run
```

## Поддерживаемые команды CLI

| Команда | Описание |
|---|---|
| `help` | Вывод справки по командам |
| `format [blocks] [block_size]` | Форматирование диска (по умолчанию 2048 блоков по 512 байт) |
| `create <file>` / `touch <file>` | Создание нового пустого файла |
| `rm <file>` / `del <file>` | Удаление файла и освобождение его цепочки блоков |
| `cp <src> <dest>` | Копирование файла с созданием новой цепочки блоков |
| `mv <src> <dest>` | Перемещение / переименование файла |
| `write <file> <text...>` | Перезапись содержимого файла |
| `append <file> <text...>` | Дозапись текста в конец файла |
| `read <file>` / `cat <file>` | Чтение и вывод содержимого файла |
| `read_range <file> <offset> <len>` | Чтение среза файла с фиксацией числа пройденных переходов (hops) |
| `ls` / `dir` | Список файлов, их размеров, блоков и даты создания |
| `stat <file>` | Полная информация о файле и цепочка его связанных блоков |
| `import <host_file> <fs_file>` | Импорт файла с хост-системы в виртуальную ФС |
| `export <fs_file> <host_file>` | Экспорт файла из виртуальной ФС на хост-систему |
| `dump [output_filepath]` | Формирование детального дампа ФС (суперблок, битовая карта, каталог, цепочки, hex-содержимое блоков) |
| `stats` | Статистика дискового ввода-вывода и метрики фрагментации |
| `bench` | Быстрая демонстрация производительности |
| `exit` / `quit` | Выход из программы |

## Режимы запуска исполняемого файла `fs_app`

```bash
# Интерактивный режим с сохранением в virtual_disk.bin:
./build/fs_app

# Работа в оперативной памяти (без сохранения на диск):
./build/fs_app --mem

# Запуск командного скрипта:
./build/fs_app --mem --script demo_script.txt

# Выполнение одиночной команды:
./build/fs_app --exec "ls"
```
